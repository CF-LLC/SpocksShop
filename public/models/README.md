# Background-removal model

`u2netp.onnx` (4.6 MB) is the small U²-Net ("U2-NetP") salient-object model.

- Source: U-2-Net by Xuebin Qin et al., https://github.com/xuebinqin/U-2-Net (Apache License 2.0).
- ONNX export as published by rembg (MIT): https://github.com/danielgatis/rembg/releases/tag/v0.0.0
- It runs in the admin's browser via onnxruntime-web (MIT). Nothing is sent to a third party.
